// ============ DEPLOYMENT FLOW ============
flow "Deployment Process" {
  1: Developer commits to GitHub main branch
  2: GitHub Actions triggers all CI workflows
  3: Backend CI: Build, test, SonarCloud scan, Docker build
  4: Frontend CI: Lint, test, build, Docker build
  5: Brain Service CI: Lint, test, Docker build
  6: All images pushed to AWS ECR
  7: Deploy pipeline triggered on all CI pass
  8: Terraform applies infrastructure changes
  9: Kubernetes manifests updated with new image tags
  10: kubectl apply deploys to EKS
  11: Rolling update strategy: new replicas → health check → old terminated
  12: Smoke tests verify deployment
  13: Slack/Email notification sent
  14: CloudWatch monitors for errors
}

  step 7: "New pods scheduled on new nodes"
  step 8: "DocumentDB read replicas handle increased connections"
  step 9: "Rate caching reduces database hits by 70%"
  step 10: "System maintains p95 latency < 300ms"
}
