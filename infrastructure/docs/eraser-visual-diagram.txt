DATA FLOW: SHIPMENT CREATION
┌─────────────────────────────────────────────────────┐
│ 1. User creates shipment in Dashboard              │
│    └─ Form validation (client-side)                │
│                                                     │
│ 2. POST /api/shipments                             │
│    └─ HTTPS → ALB → Core Service (port 5000)       │
│                                                     │
│ 3. Core Service Validation                         │
│    ├─ Tenant validation middleware                 │
│    ├─ JWT authentication                           │
│    ├─ Input DTO validation                         │
│    └─ Authorization check                          │
│                                                     │
│ 4. Business Logic Processing                       │
│    ├─ Create shipment record                       │
│    ├─ Check rate cache (30-min TTL)                │
│    ├─ Create invoice                               │
│    └─ Publish event (ShipmentCreated)              │
│                                                     │
│ 5. Database Write (DocumentDB)                     │
│    ├─ Shipments collection                         │
│    ├─ Invoices collection                          │
│    └─ Audit logs                                   │
│                                                     │
│ 6. Response to Frontend                            │
│    ├─ 201 Created + Correlation ID                 │
│    └─ Shipment details                             │
│                                                     │
│ 7. Brain Service (Async Processing)                │
│    ├─ Routing Agent calculates optimal route       │
│    ├─ Finance Agent verifies payments              │
│    ├─ Customer Service Agent sends notification    │
│    └─ Update tracking events                       │
│                                                     │
│ 8. Frontend Real-time Update                       │
│    ├─ Polling /api/shipments/{id}                  │
│    ├─ WebSocket live updates (optional)            │
│    └─ Dashboard displays updated status            │
└─────────────────────────────────────────────────────┘

TRAFFIC FLOW: REQUEST ROUTING
Internet (User)
   ↓ HTTPS:443
   ├─ ALB health check: /health (every 30s)
   ├─ Request routing (sticky sessions)
   │
   ├─ Route: /* → Dashboard (Admin Dashboard)
   ├─ Route: /api/* → Core Service (Business Logic)
   └─ Route: /brain/* → Brain Service (AI Processing)

WITHIN CLUSTER:
Core Service <→ Brain Service (Event exchange)
    ↓
    └─ MongoDB Document DB (Data persistence)
